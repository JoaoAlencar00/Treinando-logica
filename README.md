# Lógica de programação com JavaScript

Exercícios de estudo do **7 Days of Code**, com foco em comparações, funções, condicionais e estruturas de repetição.

## Conteúdo

| Arquivo | Prática |
| --- | --- |
| `7daysOfcode-treinando-logica/treinando-logica/logica.js` | Comparação entre números e strings |
| `logica-2.js` | Funções, parâmetros e respostas condicionais |
| `logica-3.js` | Escolha de área de atuação e lista de tecnologias com `prompt` |
| `ex-3/` | Versão do exercício interativo carregada por uma página HTML |

## Como executar

Para os exercícios de terminal, instale o Node.js e execute a partir da raiz:

```bash
node 7daysOfcode-treinando-logica/treinando-logica/logica.js
node logica-2.js
```

Para a versão interativa, abra `ex-3/index.html` em um navegador e responda às perguntas. Os registros do script podem ser vistos no console das ferramentas de desenvolvimento.

O arquivo `logica-3.js` da raiz também utiliza a função `prompt`, disponível no navegador. Ele não é um script de terminal Node.js.

## Objetivo de aprendizado

Praticar o raciocínio lógico e registrar a evolução dos exercícios. As versões foram mantidas em arquivos separados para consulta.
